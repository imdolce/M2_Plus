Hardware Connection & AMT49406 Driver Configuration
1 Hardware Wiring Checklist
  • MCU Pin PC3: WCH CH32V003 hardware TIM1_CH3 output (push-pull 30MHz).
  • Connect PC3 → AMT49406 SPD Pin: Connect a jumper wire from PC3 directly to the SPD pin of the driver (or to ESC PWM input).
  • I2C Separation: If PC2 (I2C SCL) was shared with SPD for I2C register access, disconnect PC2 from SPD so PC3 directly drives SPD with PWM.
  • Common Ground: Ensure MCU GND and Motor Driver Power GND are solidly connected together.
2 Required Driver Registers
  • Reg 17 bit [9] (I2C_SPD_MODE): Set to 0 (Speed determined by physical SPD pin, not I2C register).
  • Reg 10 bit [11] (SPD MODE): Set to 0 (PWM signal input mode, not analog voltage mode).
  • Reg 8 bit [12] (CLOCK_PWM): Set to 0 (PWM duty cycle demand mode; 1 is Clock frequency mode).
  • Reg 8 bit [15] (PWMIN_RANGE): Set to 0 for >2.8 kHz (e.g. 25 kHz) or 1 for ≤2.8 kHz.
  • Reg 20 [7:0] (RATED_VOLTAGE): Keep set to 20 (4.0V for 1S battery) to allow full 100% duty cycle!
